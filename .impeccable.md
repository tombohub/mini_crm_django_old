## Design Context

### Users
Primary users are people making calls to prospects from a phone. The interface is used in a practical, on-the-go sales workflow where speed, clarity, and easy touch interaction matter more than branding or decorative design.

### Brand Personality
The product should feel utilitarian, straightforward, and dependable. Emotional branding is not a priority right now. The interface should support focused task completion without adding visual noise.

### Aesthetic Direction
Use Bootstrap CSS as the primary visual system. Prefer light-mode, mobile-friendly layouts with clear hierarchy, large tap targets, and familiar controls. Keep the UI simple, clean, and operational rather than expressive or brand-led.

### Design Principles
1. Optimize for mobile calling workflows first.
2. Keep interactions obvious, touch-friendly, and fast to scan.
3. Use Bootstrap patterns unless there is a clear usability reason to deviate.
4. Favor clarity and task completion over visual personality.
5. Avoid unnecessary ornament, motion, and custom styling complexity.
